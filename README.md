# 🌸 HerHealth — Your Personal Women’s Wellness Companion

HerHealth is a beautifully designed women-focused wellness web platform that combines **health awareness, personalized lifestyle guidance, wellness resources, and self-care support** into one interactive digital experience.  

Built with a vibrant and engaging interface, HerHealth empowers users through:
- Secure login/signup experience  
- Wellness chatbot support  
- Menstrual phase-based nutrition guidance  
- Women-centric wellness shopping  
- Smooth checkout flow  
- Self-care and health education resources  

---

## ✨ Core Features

### 🔐 Authentication System
- Interactive Login & Sign Up overlay  
- LocalStorage-based user session management  
- Persistent login state  
- Personalized navbar greeting  

### 🤖 Wellness Chatbot
- Built-in women’s wellness companion chatbot  
- Interactive UI with chatbot avatar  
- Supports guidance and user engagement  

### 🥗 Eat by Phase
A dedicated menstrual-cycle nutrition guide with wellness suggestions for:
- Menstrual Phase  
- Follicular Phase  
- Ovulation Phase  
- Luteal Phase  

### 🛍️ Shop for Her
A curated women-centric wellness shopping experience featuring:
- Product cards  
- Dynamic shopping layout  
- Product details  
- Integrated checkout  

### 💳 Checkout Experience
- User-friendly checkout form  
- Payment details section  
- Order confirmation success modal  

### 🎨 Modern UI/UX
- Responsive pink-themed design  
- Animated gradients  
- Interactive cards  
- Smooth transitions  
- Mobile-friendly components
